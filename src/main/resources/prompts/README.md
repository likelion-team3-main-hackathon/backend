# AI Prompt Versioning

프롬프트 종류별 디렉터리 안에 불변 버전 파일을 둔다.

- 이미 사용한 파일은 수정하지 않는다.
- 변경할 때는 새 버전 파일을 추가한다.
- 활성 버전은 `AI_PROMPT_*_VERSION` 환경 변수로 선택한다.
- 애플리케이션 시작 시 선택한 파일이 없거나 비어 있으면 기동을 실패시킨다.
- DB `prompt_version`에는 `{version}@{sha256 앞 12자리}`를 저장해 동일한 버전명의 내용 변경도 식별한다.

JSON Schema와 서버 검증은 프롬프트와 별개인 코드 계약이므로 프롬프트만으로 출력 무결성을 보장하지 않는다.
